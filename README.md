# Kate 3D Assets

Automatically bundle eight CC0 GLB models: two sofas, two tables, and four plants.

**Download:** Open [Actions](https://github.com/candoo32-glitch/kate-3d-assets/actions/workflows/bundle-assets.yml), select a successful run, and download the `Kate-Furniture-Plants` artifact. If needed, extract the outer GitHub artifact ZIP to get `Kate-Furniture-Plants.zip`.

Original files are sourced from [hearth-webmcp](https://github.com/yadneshSalvi/hearth-webmcp) with attribution in CREDITS.md. Upload the asset ZIP to ChatGPT to integrate the models into Kate's Metal renderer.
